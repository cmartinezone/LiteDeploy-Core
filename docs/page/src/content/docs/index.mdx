## What LiteDeploy is

LiteDeploy is a JSON-driven bare-metal deployment platform for WinPE and Windows PowerShell 5.1. The admin prepares a share or USB. The device boots WinPE, finds `BootConfig.json`, and runs the runtime chain.

```text
startnet
  → BootInitializer
  → DeploymentEngine
       → PreCheck
       → SelectWorkflow
       → (planned) Setup /NoReboot + handoff
  → Progress (separate process, read-only)
```

## Two sides

| Area | Who runs it | Job |
| --- | --- | --- |
| **Manager** | Administrator | BootConfig, share ACLs, OEM driver packs, OS media |
| **Runtime** | Device in WinPE / FullOS | Discover source, validate hardware, select workflow, image |
